3 / A value that persists

Remembering a bit #

A combinational gate answers its present inputs. Memory retains a value. Feedback allows a circuit to have stable states; a controlled write changes which state it holds.

One implementation uses cross-coupled gates as a latch. A clocked flip-flop can combine latches so that input is captured at a clock edge. We now abstract this circuitry as a one-bit register: on a rising edge, copy D into Q; otherwise preserve Q.

This is an ideal edge-triggered register, not a timing simulation. Physical setup and hold times and metastability require a more detailed model. Sequential logic background.
