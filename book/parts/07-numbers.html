7 / Toward analysis

Numbers beyond a single word #

A four-bit word encodes integers from 0 through 15. We can define exact addition when the sum fits and return overflow otherwise. Wrapping modulo 16 would be a different operation.

Proposition 7.1. Checked four-bit addition is commutative as a result: exchanging the inputs preserves either the exact value or the overflow outcome.

Not checked

This exhaustive check proves a finite statement. It does not yet provide addition on arbitrarily large integers. Multiword arithmetic would need allocation rules and its own correctness argument.

Floating point is an approximation with algebraic costs

Floating point stores a finite significand and exponent. Rounding makes arithmetic practical, but familiar laws need checking. With ordinary finite operands and a fixed rounding mode, addition is commutative; associativity can fail. Special values such as NaNs also complicate equality.

A real number as a request for precision

An alternative is a procedure that, for a requested error bound, attempts to produce a rational enclosure. A successful result includes evidence that the value lies inside. More precision can require more memory and work.

For √2, start with [1, 2]. Bisect the interval. If the midpoint squared is below 2, retain the upper half; otherwise retain the lower half. Squaring and comparison can use exact integer arithmetic.

The engine checks the enclosure inequalities after each successful refinement. If the next comparison exceeds the bit limit, the last enclosure survives. Nothing has constructed an infinite digit string.

Research direction 7.2. A computable-real representation should supply arbitrarily accurate approximations when given sufficient resources, with a specified convergence guarantee. A procedure that can fail at every finer precision does not establish such a real.

To build analysis we still need rational arithmetic with explicit bounds, compatible refinement, an error specification, and proofs that operations preserve it. General equality of computable reals is not decidable. Continuity, limits, and differentiation need constructive hypotheses and witnesses; finite experiments alone will not establish them.

On a fixed device we can execute only finitely much of this process. A theory may reason about a family of larger finite budgets. Keeping that distinction visible is the foundation we want to investigate.
