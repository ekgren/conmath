A computer small enough to see #

Give the machine four words of data memory, each four bits wide. The accumulator A holds a working word. The two-bit program counter PC selects an instruction; the four-bit instruction register IR holds the instruction just fetched.

Definition 4.1 · Instruction. An instruction is a four-bit word. Its first two bits select HALT (00), LOAD (01), NOT (10), or STORE (11). Its last two bits select a data address for LOAD and STORE.

Each Step performs a whole instruction: fetch into IR, decode, then update state. This is a register-transfer model. A physical processor would split that work into clocked phases.

With four steps, 0101 is loaded, complemented to 1010, stored at address 01, and the program halts. Try a budget of two. The machine stops before STORE: the result is out of steps, not a failed logical claim.
