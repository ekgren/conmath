1 · Our contract

Conmath begins with what we can construct, distinguish, store, transform, and check. It does not begin by assuming a completed universe of mathematical objects.

This first chapter makes one deliberately small commitment. We will admit a type with two values. Nothing here assumes natural numbers, sets, induction, or an unbounded process.

Construction An explicit value or finite procedure accepted under the current rules and resource envelope.

2 · Construct Bit

Two values that are not the same.

We name the type Bit and introduce exactly two constructors. The names describe distinction, not quantity.

Definition · conmath.bit.v1
Bit  : Type
low  : Bit
high : Bit

A logical Bit requires one bit of representation. Our browser simulation uses more physical memory because JavaScript has its own object model. We will never confuse those two accounts.

0low
distinguishable
1high
The symbols 0 and 1 are encodings shown by the machine. At this point they are not yet natural numbers.

3 · Negation

Exchange one distinction for the other.

Negation is completely defined by its two cases:

Operation · conmath.bit.not.v1
not : Bit → Bit

not(low)  = high
not(high) = low
Bit NOT Bit

This operation has a direct circuit interpretation: a NOT gate. It also has a complete finite table, so every possible input is visible rather than hidden behind an example.

    5 · First proposition

    Return after two negations.

    We claim that applying not twice returns every Bit to itself. The universal symbol ranges over the two constructed values of Bit—nothing more.

    Theorem · conmath.bit.double-negation.v1

    ∀ b : Bit,
    not(not(b)) = b

    A proof by cases must provide evidence for low and high. Each branch normalizes both sides, then applies reflexivity only if they are identical.

    Boundary

    We have not constructed a number.

    We have two named values, a finite operation, a finite machine, and one checked proposition. Calling the encodings 0 and 1 does not yet give us counting, succession, or arithmetic. Those must be built.
